# 98 键三模机械键盘 · 操作指南（社区整理版）

> 本指南由社区根据公开说明书整理，仅转述事实性操作信息，不包含任何厂商素材。
> 与厂商无关，也不构成保修依据。型号覆盖：98 键三模机械键盘（101 键含 Fn 层）。

## 三段式开关

键盘顶部（或背面）有三段拨杆：

| 位置       | 模式      |
| ---------- | --------- |
| 拨到**左** | 蓝牙      |
| 拨到**中** | 有线 USB  |
| 拨到**右** | 2.4G 无线 |

## 模式指示灯

- NUM、CAPS、Win 锁：对应键白灯亮起
- 蓝牙通道指示：BT1 蓝、BT2 绿、BT3 红
- 2.4G 指示：黄灯
- 配对状态：指示灯闪烁 = 正在配对；配对成功常亮约 3 秒；30 秒未找到设备自动退出配对并休眠

## 连接方法

### 有线

拨到中间挡位，插上 Type-C 线即插即用。

### 蓝牙

1. 拨到蓝牙挡位
2. `Fn+Q` / `Fn+W` / `Fn+E` 分别选择 3 个蓝牙通道（蓝/绿/红指示）
3. **长按对应组合键 3 秒**进入配对，指示灯闪烁
4. 在电脑/手机上搜索并连接
5. 短按 `Fn+Q/W/E` 可在已配对设备间切换

### 2.4G

出厂已与接收器配对，拨到 2.4G 挡位、插入接收器即可使用。
若需强制重新配对：`Fn+R` 长按 3 秒进入配对，指示灯闪烁后插接收器。

## 系统切换

- `Fn+A`：切到 WIN 模式（键盘绿灯闪一下）
- `Fn+S`：切到 MAC 模式（键盘蓝灯闪一下）

## 充电与低电保护

- **任意无线模式下插 USB 线即可充电**（边充边用）
- 只支持**连接电脑 USB 口充电**，充电头/移动电源不支持
- 充电中：红色指示灯常亮；充满后绿灯亮数秒，之后恢复默认灯效
- 低电量：红灯快速闪烁
- 低电保护：电量降到约 3.1V 时自动关机；插上有线恢复使用
- 省电休眠：无操作约 10 分钟后键盘灯自动熄灭；按任意键唤醒（蓝牙模式需重新连接）

## 背光灯效

- 19 种灯效，开机时灯光绕键盘跑一圈后恢复上次关机前的灯效
- 灯效按固定顺序循环切换，最后一个模式为 OFF

| 组合键          | 功能                             |
| --------------- | -------------------------------- |
| `Fn+Enter`      | 切换灯效（循环 19 种）           |
| `Fn+T`          | 背光总开关（带记忆，重开机保留） |
| `Fn+↑` / `Fn+↓` | 亮度 + / −                       |
| `Fn+←` / `Fn+→` | 灯效速度 − / +                   |
| `Fn+空格`       | **电量检查**（见下）             |

## 电量检查（Fn+空格）

仅在**无线模式 + 电池供电**时有效：

- 按下 `Fn+空格`，背光熄灭，数字键 1–0 亮起显示电量档位
- 1 = 10%，1+2 = 20%……依此类推，1–0 全亮 = 100%
- 灯色：**低于 30% 红色**；**30%–50% 黄色**；**50% 以上绿色**

## 多媒体与系统组合键

| 组合键             | 功能                                                            |
| ------------------ | --------------------------------------------------------------- |
| `Fn+F1` ~ `Fn+F12` | 多媒体控制（播放/暂停、停止、上一曲、下一曲、静音、音量调节等） |
| `Fn+Win+L`         | 锁定 Win 键                                                     |
| `Fn+Esc`           | 长按 3 秒恢复出厂设置（白灯指示）                               |

## 常见问题

| 问题         | 处理                                                            |
| ------------ | --------------------------------------------------------------- |
| 键盘没反应   | 检查三段开关挡位；无线模式确认接收器已插或已完成配对            |
| 灯光不亮     | `Fn+T` 是否关过灯；无操作 10 分钟后会自动熄灯节能，按任意键唤醒 |
| 充不进电     | 确认插的是**电脑 USB 口**（充电头不支持）；充电时红灯应常亮     |
| 电量显示不准 | 固件按电压估算，充电时读数会偏高，拔线后回落，属正常现象        |
| 无线连接丢失 | 蓝牙重连失败时重新配对；2.4G 可用 `Fn+R` 长按 3 秒强制配对      |
